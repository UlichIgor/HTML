# Довідник атрибутів HTML

Атрибути додають елементам параметри та додаткову інформацію. Їх записують у початковому тезі:

```html
<a href="https://example.com" target="_blank" rel="noopener noreferrer">
  Відкрити сайт
</a>
```

Тут `href`, `target` і `rel` — атрибути елемента `a`.

## 1. Глобальні атрибути

Глобальні атрибути можна використовувати на більшості HTML-елементів. Це не означає, що кожен атрибут має однаковий ефект на кожному елементі.

| Атрибут | Призначення |
|---|---|
| `id` | Унікальний ідентифікатор елемента в межах документа |
| `class` | Один або кілька класів для CSS та JavaScript |
| `title` | Додаткова підказка; не замінює видимий підпис |
| `lang` | Мова вмісту елемента |
| `dir` | Напрямок тексту: `ltr`, `rtl` або `auto` |
| `hidden` | Позначає, що елемент не потрібно показувати |
| `tabindex` | Керує можливістю та порядком клавіатурного фокусу |
| `contenteditable` | Дозволяє редагувати вміст елемента |
| `draggable` | Визначає, чи можна перетягувати елемент |
| `spellcheck` | Дозволяє перевірку правопису |
| `translate` | Підказує, чи перекладати текст |
| `data-*` | Зберігає власні дані, наприклад `data-product-id` |
| `accesskey` | Задає клавіатурну комбінацію; використовуйте обережно |
| `style` | Додає CSS безпосередньо до елемента; для великих стилів краще окремий CSS-файл |

### Приклади глобальних атрибутів

```html
<p id="intro" class="lead" lang="uk">
  Вступний абзац українською мовою.
</p>

<button type="button" data-action="save">
  Зберегти
</button>

<p contenteditable="true">
  Цей текст можна редагувати прямо в браузері.
</p>
```

## 2. Атрибути посилань і ресурсів

| Атрибут | Елементи | Призначення |
|---|---|---|
| `href` | `a`, `area`, `link` | Адреса переходу або ресурсу |
| `target` | `a`, `form`, `base` | Контекст відкриття |
| `rel` | `a`, `link` | Відношення до цільового ресурсу |
| `download` | `a` | Підказує браузеру завантажити ресурс |
| `src` | `img`, `script`, `iframe`, `audio`, `video` та ін. | Адреса ресурсу |
| `alt` | `img`, `area`, `input` image | Текстова альтернатива зображенню |
| `width`, `height` | Відповідні медіа та інші елементи | Розміри елемента |
| `loading` | `img`, `iframe` | Керування відкладеним завантаженням |

```html
<a href="https://example.com" target="_blank" rel="noopener noreferrer">
  Відкрити приклад у новій вкладці
</a>

<img
  src="images/cat.jpg"
  alt="Рудий кіт спить на дивані"
  width="600"
  height="400"
  loading="lazy"
>
```

Для декоративного зображення, яке не додає змісту, використовуйте порожній альтернативний текст: `alt=""`.

## 3. Атрибути форм

| Атрибут | Призначення |
|---|---|
| `action` | URL, куди надсилаються дані форми |
| `method` | Метод надсилання: зазвичай `get` або `post` |
| `name` | Ім'я поля; за ним дані передаються під час надсилання |
| `type` | Тип поля input |
| `value` | Початкове або поточне значення |
| `placeholder` | Коротка підказка; не замінює label |
| `required` | Робить поле обов'язковим |
| `min`, `max` | Мінімальне та максимальне значення |
| `minlength`, `maxlength` | Мінімальна та максимальна довжина тексту |
| `pattern` | Регулярний вираз для перевірки введення |
| `autocomplete` | Підказка браузеру щодо автозаповнення |
| `multiple` | Дозволяє кілька значень для підтримуваних полів |
| `checked` | Початково вибраний checkbox або radio |
| `selected` | Початково вибраний option |
| `disabled` | Вимикає елемент керування |
| `readonly` | Забороняє редагування, але значення може надсилатися |
| `for` | Пов'язує label з елементом за його id |

### Приклад форми

```html
<form action="/contact" method="post">
  <label for="email">Електронна пошта</label>
  <input id="email" name="email" type="email" autocomplete="email" required>

  <label for="message">Повідомлення</label>
  <textarea id="message" name="message" rows="4" minlength="10" required></textarea>

  <button type="submit">Надіслати</button>
</form>
```

**Важливо:** HTML-перевірка полів покращує зручність, але не замінює серверну перевірку. Сервер має перевіряти отримані дані самостійно.

## 5. Події та JavaScript

Події — це сигнали про дії користувача або зміни стану сторінки: клік, введення тексту, надсилання форми чи завантаження документа.

Для нового коду реєструйте обробники через JavaScript `addEventListener()`, а не записуйте код у HTML-атрибутах на кшталт `onclick`.

| Подія | Коли виникає |
|---|---|
| `click` | Користувач активує елемент |
| `input` | Значення поля змінюється під час введення |
| `change` | Значення елемента змінено та підтверджено |
| `submit` | Форма надсилається |
| `focus` | Елемент отримує фокус |
| `blur` | Елемент втрачає фокус |
| `keydown` | Клавішу натиснуто |
| `keyup` | Клавішу відпущено |
| `DOMContentLoaded` | HTML розібрано, DOM побудовано |
| `load` | Завантажено сторінку та залежні ресурси |
| `resize` | Змінився розмір вікна |
| `scroll` | Прокручується документ або елемент |

### Приклад addEventListener

HTML:

```html
<button id="hello-button" type="button">Натисни мене</button>
<p id="result" aria-live="polite"></p>
```

JavaScript у файлі script.js:

```javascript
const button = document.querySelector("#hello-button");
const result = document.querySelector("#result");

button.addEventListener("click", () => {
  result.textContent = "Вітаю! Подія click спрацювала.";
});
```

Підключення скрипту в HTML:

```html
<script src="script.js" defer></script>
```

Не додавайте обробники подій до довільних елементів: подія має бути зареєстрована на відповідному елементі або об'єкті. Наприклад, `resize` належить вікну, а `submit` — формі.

## 6. Застарілі атрибути та помилки

Не використовуйте у новому коді застарілі презентаційні атрибути:

- `align`, `bgcolor`, `valign` — оформлення виконуйте через CSS.
- `background` — для фону використовуйте CSS `background` або `background-image`.
- `height` та `width` не є універсальними атрибутами для будь-якого елемента; використовуйте їх лише там, де вони передбачені HTML.
- `contextmenu` та `dropzone` не слід подавати як актуальні глобальні атрибути.
- `onkeypress` застаріла подія; для клавіатурної взаємодії зазвичай використовують `keydown` або `keyup`.
