# HTML — навчальний довідник українською

Повноцінний україномовний навчальний проєкт з **HTML**: інтерактивні уроки, тести, редактор коду, фінальний іспит і довідники — від базової структури документа до семантичної розмітки, доступності, форм, таблиць і медіа.

> HTML (HyperText Markup Language) — мова розмітки гіпертексту. Вона описує структуру та зміст сторінки. Для оформлення використовують CSS, для інтерактивної поведінки — JavaScript.

## 🧱 Базовий шаблон HTML

```html
<!doctype html>
<html lang="uk">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Назва сторінки</title>
</head>
<body>
  <h1>Привіт, світе!</h1>
  <p>Це мій перший HTML-документ.</p>
</body>
</html>
```

- `<!doctype html>` вмикає стандартний режим відображення браузера.
- `lang="uk"` визначає основну мову документа.
- `meta charset="UTF-8"` задає кодування символів.
- `meta name="viewport"` допомагає коректно відображати сторінку на мобільних пристроях.
- `title` задає назву вкладки браузера.
- `body` містить вміст сторінки.

## 🏷️ Тег, елемент та атрибут

- **Тег** — запис у кутових дужках, наприклад `<p>`.
- **Елемент** — початковий тег, вміст і, за потреби, кінцевий тег: `<p>Текст</p>`.
- **Атрибут** — додаткова інформація в початковому тезі: `<a href="https://example.com">Сайт</a>`.

## ✅ Хороші практики

- Використовуйте семантичні елементи за їхнім призначенням.
- Додавайте змістовний `alt` для інформативних зображень; декоративним зображенням задавайте `alt=""`.
- Пов'язуйте поля форм з елементами `label`.
- Дотримуйтеся логічної ієрархії заголовків.
- Для таблиць даних використовуйте `caption` і заголовкові комірки `th`.
- Задавайте мову документа через `lang`.
- Не використовуйте застарілі презентаційні елементи на кшталт `font` чи `center` — оформлення належить CSS.
- Для інтерактивності реєструйте події в JavaScript через `addEventListener()`, а не через HTML-атрибути на кшталт `onclick`.
- Перевіряйте розмітку через [Nu HTML Checker](https://validator.w3.org/nu/).

## 🧪 Як перевірити сторінку

1. Відкрийте `index.html` у браузері.
2. Перевірте посилання, зображення та поля форми.
3. Зменште ширину вікна, щоб перевірити мобільну версію.
4. Пройдіть сторінку клавішею Tab — фокус має бути помітним.
5. Перевірте HTML через [Nu HTML Checker](https://validator.w3.org/nu/).
